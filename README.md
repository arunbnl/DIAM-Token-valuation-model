# DIAM-Token-valuation-model
Particularly its blockchain ecosystem, digital assets, tokenomics, network activity and financial aspects — and I turned that research into something practical.
As I studied the project and the broader blockchain ecosystem, I built a structured set of Excel-based financial models and analyses around DIAM.
📊 Projects I developed:
🔹 DIAM Token Valuation Model — Executive Summary
A consolidated overview of the valuation framework, assumptions and scenario outputs.
🔹 DIAM Token — Model Assumptions & Tokenomics
Detailed modelling of key assumptions related to token supply, adoption, growth, utility and other valuation drivers.
🔹 DIAM Token — Adapted DCF Valuation Model
An adapted DCF framework with Bear, Base and Bull scenarios to understand how different assumptions can influence potential valuation outcomes.
🔹 DIAM Token — Supply Schedule & Burn Mechanics
Analysis of token supply dynamics, circulating supply and the potential effect of token-burning mechanisms.
🔹 DIAM Token — NVT Ratio Analysis
Studied Network Value to Transactions (NVT) as a way of analysing network valuation relative to transaction activity.
🔹 DIAM Token — Sensitivity Analysis
Tested how changes in key assumptions could impact the model outputs and valuation.
